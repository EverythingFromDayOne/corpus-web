# @corpus/api-client

Generated from the NestJS OpenAPI document. **Never hand-edit.**

`packages/api-client` is produced in CI from `apps/api`'s `@nestjs/swagger` output.
An undecorated endpoint is an invisible endpoint; this package will not contain it.

Until the API exists, this directory is a placeholder so the workspace graph is
complete. Do not add fetch wrappers, types, or "temporary" clients here.
