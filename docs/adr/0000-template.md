# ADR-NNNN: <short imperative title>

- **Status:** proposed | accepted | superseded by ADR-NNNN | rejected
- **Date:** YYYY-MM-DD
- **Deciders:** <who>

## Context

What is true that forces a decision. Constraints, prior commitments, what already exists.
State facts, not preferences. If a claim here is unverified, mark it.

## Options considered

For each: what it is, what it costs, what it buys. Include the option you rejected fastest
— an ADR that lists only plausible options is advocacy, not a record.

## Decision

One paragraph. What we are doing, in the present tense.

## Consequences

What becomes easier. What becomes harder. What we can no longer do without revisiting this.
Include the reversal cost — how expensive is it to change our minds in six months.

## Revisit when

The specific condition that should reopen this. If you cannot name one, the decision is
either obvious (skip the ADR) or under-analysed.
